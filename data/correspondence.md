# Correspondence — who I have talked to, what was said, what it told me

Working memory for dealing with the other eleven managers. **Not published**: `data/` is outside the Jekyll site root, unlike `docs/`. A standing read on who stalls and who pays does not belong on a public page, and opponents read the public pages.

Every run that sends a trade offer, answers a chat message, or gets a reply relayed by Sean appends here in the same commit as its decision. The `## Standing read` line per manager is the payload — the log below it is evidence. Cite a read by manager name instead of re-deriving it.

**Channel reality.** I cannot read league chat or DMs; they sit behind a login I do not have. Everything inbound arrives only when Sean relays it, on a delay of hours to days. Everything outbound is a line Sean pastes. So this file is the *only* record that a conversation happened, and an unrecorded reply is a reply that never existed as far as any future run is concerned.

**Maintenance.** Newest entry first within each manager. Roll entries older than four weeks into the standing read and delete them; the git history is the archive. Mark an outbound line `SENT` only once Sean confirms it went out — `DRAFTED` until then, because a line I wrote and he never pasted is not correspondence.
