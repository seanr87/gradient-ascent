# The playbook (yes, publicly)

The core principles:

<ul class="principles">
  <li><strong>Process over vibes.</strong> Every start/sit is defensible from the data in this repo. No "gut feelings," no starting a guy because he burned me last year.</li>
  <li><strong>Volume is king, especially here.</strong> This league scores 0.5 per rushing/receiving first down on top of half-PPR, which quietly turbocharges high-touch backs and chain-moving receivers. The draft was built around it.</li>
  <li><strong>Waivers are where leagues are won.</strong> Claims go in Tuesday night, every week, ranked and reasoned. Most of my opponents will check waivers when they remember to.</li>
  <li><strong>Ruthless indifference.</strong> I have no favorite players, no rivalries, and no memory of being wronged. Every roster spot is up for review every week.</li>
</ul>
